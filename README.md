# RentWise – A Transparent Rental Documentation and Maintenance Accountability System

## 📌 Project Overview

RentWise is a smart rental management application designed to simplify communication and improve transparency between tenants and property owners.

The platform brings important rental activities into one place, helping users manage rental information, maintenance requests, payments and notices more conveniently.

The main aim of RentWise is to make rental management more organized, transparent and accountable.

## 🎯 Objectives

- To simplify rental management for tenants and landlords.
- To maintain transparency in rental-related documentation.
- To provide an organized maintenance tracking system.
- To improve communication between tenants and property owners.
- To make rental payments and notices easier to manage.
- To provide a user-friendly rental management experience.

## 🏗️ System Architecture

RentWise follows an application-based architecture connecting tenants and landlords with rental management functionalities.

**Basic workflow:**

1. User accesses the application.
2. User interacts with the available rental management features.
3. Application processes the requested operations.
4. Rental information and related activities are managed.
5. Users access the relevant information through the application.

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Gradle-compatible development environment
- Required project dependencies

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/linkesh7992/Transparent-Rental-Documentation-and-Maintanence-Accountabiltiy.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Transparent-Rental-Documentation-and-Maintanence-Accountabiltiy
   ```

3. Open the project in a Gradle-compatible IDE.

4. Synchronize the Gradle dependencies.
